Curso Superior de Tecnologia

Desenvolvimento de Software Multiplataforma

Formação para projetar, desenvolver e testar software para web, desktop, dispositivos móveis, nuvem e internet das coisas — dos fundamentos de programação à segurança da informação e à inteligência artificial.

Coordenação: Prof. Me. Edson Company Colalto Junior
01 — Apresentação
Sobre o curso

O Curso Superior de Tecnologia em Desenvolvimento de Software Multiplataforma prepara o estudante para criar soluções que funcionam em diferentes ambientes — sites, aplicativos desktop, dispositivos móveis, sistemas em nuvem e internet das coisas — combinando teoria e prática desde o primeiro semestre.

Entre as disciplinas do curso estão matemática para computação, álgebra linear, redação técnica, ética profissional e patente, metodologias ágeis para gestão de projetos de software e inglês, além de lógica de programação, programação para desktop, dispositivos móveis e web, experiência do usuário, computação em nuvem, inteligência artificial, segurança da informação, internet das coisas, banco de dados e engenharia de software.

O tecnólogo formado realiza análise estatística de dados para apoiar clientes em tomadas de decisão e pode coordenar projetos e equipes de desenvolvimento de software.

03 — Mercado
Perfil profissional

O tecnólogo formado projeta, desenvolve e testa software para múltiplas plataformas, aplicações em nuvem e internet das coisas. Seleciona e aplica conceitos, métodos e tecnologias de linguagens de programação, banco de dados, engenharia de software, segurança da informação e inteligência artificial para propor soluções tecnológicas.

Também realiza análise estatística de dados para apoiar clientes em tomadas de decisão, além de poder assumir a coordenação de projetos e equipes de desenvolvimento.
